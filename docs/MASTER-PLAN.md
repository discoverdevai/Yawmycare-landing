# الخطة الرئيسية: SEO · GEO · UX · UI · المنتج · التسويق · البراندينج

الهدف: صفحة تجذب أصحاب الحضانات في مصر والسعودية وأمريكا، تشرح المنتج بصدق، وتحوّل الزيارة إلى طلب عرض.
مبنية على: `docs/REVIEW-COMPETITIVE.md` · `docs/research/*` · `docs/NEXT-PLAN.md` · `docs/SITEMAP-PLAN.md` · `docs/ROADMAP.md`.

## قرارات ثابتة
- لا آراء ولا مؤسسين منشورين قبل موافقة حقيقية (DECISIONS 27-28).
- لا ادعاء بدون شاشة أو حقيقة مؤكدة. لا فواتير/NFC/مواصلات.
- لا أرقام أو أسعار أو أسماء مختلقة. القيم الناقصة تبقى مخفية.

## 5) SEO
| الوضع | المطلوب | التنفيذ |
|---|---|---|
| الأساسيات سليمة (عناوين، hreflang، canonical، OG، sitemap، JSON-LD) | الحفاظ عليها + نمو | `scripts/seo-verify.mjs` في كل بناء (CI) |
| صفحة واحدة لكل لغة | صفحات تدعم البحث | خصوصية/شروط/تواصل (عند توفر النص)، ثم صفحة أسعار، عملاء، مدونة (`SITEMAP-PLAN.md`) |
| كلمات بحث | تغطية عربية طبيعية | بحث كلمات ("برنامج إدارة الحضانات"، "تطبيق حضانة"، "نظام متابعة الأطفال")، وربطها بالعناوين والأسئلة |
| سرعة | LCP < 2.5s، CLS < 0.05 | صور الهيرو الجديدة بـAVIF، Lighthouse في CI |
| روابط خارجية | سمعة | Google Business Profile، أدلة حضانات، شراكات |

| إشارات محلية | عناوين وأرقام حقيقية لكل بلد، لغة محلية في الإعلانات (مصري/خليجي) |

## 6.5) التسويق
| المطلوب | التنفيذ |
|---|---|
| قناة المبيعات الأساسية: واتساب | زر واتساب عائم + في الهيرو + في النموذج (جاهز، يحتاج الأرقام) |
| إثبات | حضانة واحدة حقيقية بالاسم ثم 3 + دراسة حالة؛ أرقام حقيقية لما تتوفر |
| عرض | أسعار ظاهرة حسب المنطقة؛ تجربة/عرض سريع بخطوتين |
| محتوى | فيديو 60-90 ثانية بالعربي؛ مقارنة "ليه مش واتساب وإكسل" (جاهزة)؛ مدونة وأدلة |
| إعلانات | صفحات هبوط حسب الجمهور (مالك / ولي أمر / مدرسة دولية) ولغة (مصري/فصحى)؛ حملات جوجل وميتا بكلمات بحث عربية |
| قياس | تحليلات بدون كوكيز (جاهزة بعد الإعداد): طلبات العرض، نقرات واتساب، بدء/إرسال النموذج، العمق |

## مؤشرات النجاح
Lighthouse (موبايل) أداء ≥ 90 / وصول 100 / SEO 100 · LCP < 2.5s · معدل طلب العرض لكل زائر (ثم A/B) · نقرات واتساب · إكمال النموذج > 60% · ≥ 3 عملاء مسمّين · صفر محتوى مؤقت.

## ما أحتاجه منك (مرتبة بالأثر)
1. لقطات شاشة التطبيق بالعربي (أو قرار تخفيف ادعاءات العربي)
2. السعر لكل منطقة + أرقام الواتساب/الهاتف
3. أول حضانة موافقة على نشر اسمها وكلمتها
4. تأكيد قدرات المنتج الفعلية
5. الخطوط المرخّصة + الشعار SVG
6. قرار: صور حقيقية أم رسومات بأسلوب واحد
7. نصوص الخصوصية والشروط + عنوان استقبال النموذج + الاستضافة

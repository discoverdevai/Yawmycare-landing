## What is good

- Rules in CLAUDE.md are actually met: zero physical-direction utilities, zero raw hex in components, zero hard-coded user-facing strings (one punctuation separator), no `!important`, no `any`/`@ts-ignore`; `astro check` is clean.
- i18n is solid: one pair of files per section, the AR dictionary is typed against EN, and every EN/AR pair has identical keys and array lengths (verified by script).
- The shared kit is genuinely reused: all 13 sections build on `Section` / `SectionHeader` / `BlobCard` / `Button`, wave directions match the spec table, and `Button` throws at build time when an icon-only variant lacks a label.
- `BlobCard` chooses SVG vs rounded card by its own container width, grows with Arabic copy, and keeps strokes crisp via CSS variables: a good answer to the mobile-blob problem.
- Accessibility craft: native `<dialog>` with focus return, `aria-labelledby` swapped per state, honeypot hidden with `inert`; FAQ follows the WAI-ARIA accordion keyboard pattern with a no-JS fallback; scroll-spy and mobile menu degrade without JS; reduced-motion stills for the animated illustrations in three sections.
- DemoModal's script is careful: only `textContent` writes, JSON POST with timeout and `AbortController`, `credentials: "omit"`, https-only endpoint check, emits analytics events instead of coupling to a vendor.
- Fonts: drop-in licensed WOFF2 detection with no 404s and a documented stand-in strategy; `font-synthesis: none`.
- Comments explain why (Figma node ids, contrast measurements, the 72px overlap decision), which makes the Figma-driven magic numbers traceable.

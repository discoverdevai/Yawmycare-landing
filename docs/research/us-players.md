## 2. Patterns that repeat across winners

| Pattern | Evidence | Strength |
|---|---|---|
| Hero = outcome claim + one primary "demo" CTA + a softer secondary (video tour / pricing) | Brightwheel, Famly, Playground, illumine, Lillio | Strong; "Get/Book a demo" is the universal verb |
| Number-based proof right under the hero (rating + count) | Brightwheel 4.9/160k, Lillio 4.9/35k, Playground 4.96/10k, Famly 1M+, Procare 40k | Near-universal; Capterra/G2 names carry the credibility |
| Logo wall + named testimonials with centre name/location/role | Brightwheel, Famly, ParentSquare, illumine | Standard |
| Pricing hidden behind a form | Brightwheel, Procare, Lillio, Kangarootime, Jackrabbit, Playground, illumine (visible only as plan names) | Majority hide. Famly (UK), Transparent Classroom, Daily Connect publish |
| High demo friction at leaders: multi-step forms, gated calculators | Brightwheel 12 steps, Procare calculators | Opportunity: illumine's short booking and Daily Connect's no-card trial are lighter |
| ROI / savings calculators as lead capture | Brightwheel (2), Procare (3), Daily Connect | Common |
| Parent app is a module, not the hero; hero speaks to admins | Parents appear in role cards (Famly, Brightwheel) | Parent benefit is the secondary story; store badges mostly in footer |
| Compliance language is mostly feature-level (licensing, ratios, CACFP) plus uptime figures; formal certs rare on homepages | Only Learning Genie and Wonderschool show certs; illumine only in schema; COPPA/FERPA barely named on childcare pages | Gap: a plain, specific trust block would stand out |
| AI is the 2026 headline feature | Procare RoomRunner, Playground Camber, illumine AI agents, Brightwheel AI, Daily Connect "Ask AI" | Table stakes in the US, not required for a MENA launch |
| Warm, short, benefit-led copy; humour at Famly and Daily Connect | All | Famly's "Admin stole the joy" is the most distinctive line |

## 3. Best practices worth copying

| Practice | From | Why |
|---|---|---|
| Role selector or audience cards high on the page (owner / teacher / parent) | Brightwheel, Famly, ParentSquare | One page serves three audiences |
| Short demo-booking modal (name, phone, centre count, role, then date/time) | illumine | Yawmy's modal has 5 fields; keep it light |
| Rating + count strip under the hero naming the review source | Brightwheel, Lillio | Fast credibility, but only once real reviews exist |
| Public flat price with "no setup fee, free support, cancel with notice" bullets | Famly, Transparent Classroom, Daily Connect | Differentiator against the hidden-price majority |
| A fairness hook in pricing ("pay only for enrolled children", "nothing in summer") | Transparent Classroom | Memorable |
| Interactive "try it" widget instead of video | Playground | Higher engagement than static screenshots |
| Real product UI shown per role | Famly, Brightwheel | Makes parent value concrete |
| "No pushy sales calls" reassurance | Daily Connect | Lowers fear of a form-heavy category |
| Trust block with specific controls (who sees what, retention, consent, certs only if real) | Transparent Classroom, Learning Genie | Child data is the top objection |
| Onboarding timeline and free migration | Playground | Answers "how hard is switching" |

## 4. What NOT to copy for a MENA product

| Do not copy | Reason |
|---|---|
| FERPA / COPPA / CACFP / US state-licensing language | Not applicable. Use local equivalents only if real (e.g. UAE/KSA/Egypt ministry or KHDA/ADEK licensing, regional data-protection laws). Never imply certifications you do not hold |
| "#1" claims and "4.9 / 160,000 reviews" style numbers | No review base yet; invented numbers destroy trust. Use first-10-partners honesty instead |
| Hidden pricing plus 12-step forms | Hurts conversion; keep the flat fee visible |
| Gated ROI calculators with US hourly rates | Wrong currency and labour assumptions |
| Email/SMS-only contact | MENA owners expect WhatsApp and phone calls |
| Western stock imagery and UK/US idiom ("nappy", "pre-K") | Use regional faces and settings; be careful with children's photos |
| Translation as a bolt-on ("20+ languages", Arabic unnamed) | Arabic from day one is the wedge: show real RTL screens |
| USD-only per-child pricing | Show local currency and VAT note |
| AI-agent headlines | Premature; claims to substantiate |
| Anonymous testimonial walls | Use real, named, locally credible quotes |
